# P008 倍行镜 JoinWitness

LEFT JOIN 键倍增归因与反例生成器。

## 技术栈与版本要求

- Node.js 24 LTS
- React 19.3.1
- TypeScript 5.9.3
- Vite 8.3.5
- Vitest 4.1.12
- Playwright 1.64.1

## 常用脚本

```bash
npm ci              # 纯净复现依赖
npm run typecheck   # TypeScript 类型检查
npm run test        # Vitest 单元/冒烟测试
npm run build       # Vite 生产构建
npm run preview     # 预览生产构建 (http://127.0.0.1:4173)
npm run test:e2e    # 端到端测试
```
